## Цель

Добавить опциональные подсказки по облачному провайдеру и ASN (`--asn`) для каждого хоста: к какому автономному сетевому блоку принадлежит IP и, если распознаётся, какому cloud-провайдеру. Это чистые метаданные идентичности, дополняющие опись; не территория `nmap`.

## Область

- Сопоставлять IP с ASN и провайдером по поддерживаемым локальным данным (bundled-таблица префиксов) или опциональному внешнему источнику, включаемому явным флагом.
- Внешний источник по умолчанию выключен; документировать, что он шлёт целевые IP наружу — это должно быть осознанным выбором оператора при аудите собственной инфраструктуры.
- Поля вывода: `asn`, `asn_org`, `cloud` — метаданные (вывод), рядом с фактами; отсутствие данных → пусто, а не выдуманное значение.
- Обогащение опционально и управляется независимым флагом; по умолчанию выключено.

## Критерии приёмки

- [x] `--asn` добавляет `asn`/`asn_org`/`cloud` там, где IP сопоставился; иначе поля отсутствуют.
- [x] Работает офлайн на bundled-таблице и не делает сетевых запросов (ни DNS, ни API).
- [x] Внешний источник в этой итерации сознательно не реализован: данные наружу не уходят, поведение описано в README.
- [x] Тесты покрывают попадание/промах, специфичный Azure-префикс поверх широкого AWS, IPv6 и CLI-офлайн (`--Pn --asn`).

## Вне области

- Полный WHOIS-энумератор.
- Активные пробы к API провайдеров.


## Реализация

- `src/asn.rs` — bundled-таблица `(prefix, asn, org, cloud)` для AWS/GCP/Azure/Cloudflare/Fastly/DigitalOcean/GitHub, IPv4 и IPv6; `lookup(IpAddr) -> Option<AsnInfo>`, парсинг таблицы один раз через `OnceLock`.
- `src/main.rs` — `--asn` на `ps` и `as`; lookup по уже известному IP, без новых проб; поля добавляются в записи и текст.
- `src/output/mod.rs` — `asn`, `asn_org`, `cloud` и колонки CSV/grep (19 колонок).
- Ограничение: таблица неполная и может устаревать; это подсказка, а не реестр. Внешний источник не реализован осознанно.
