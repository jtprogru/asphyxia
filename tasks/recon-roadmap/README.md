## Решения, изменившие первую редакцию роадмапа

1. Decoy-адреса убраны. Цель — аудит собственной инфраструктуры; обфускация атрибуции бессмысленна и попадает под запрет evasion.
2. Добавлено UDP-пробирование сервисов (задача 03): в коде уже есть базовый `--udp`, но без payload-проб и обработки ICMP unreachable.
3. Фаза 3 урезана под существующий хендофф в `nmap`: убраны полный сбор TLS-сертификатов и risk-hints; оставлена дешёвая идентичность (PTR, классификация, ASN).
4. Сравнение во времени (Фаза 4) работает по `ScanRecord` из структурированного вывода, а не по state-файлам `src/resume.rs` — обоснование в задаче [13](13-compare-results.md).
