# Отчёты в Markdown и HTML

Фаза: 5 — Топология и отчётность
Статус: Выполнено (выпущено в 0.11.0, 2026-11-08)
Зависит от: 13-compare-results (те же записи), обогащается 10–12 (идентичность активов)
Роадмап: docs/recon-roadmap.md (Фаза 5)

## Цель

Генерировать человекочитаемые отчёты в Markdown и HTML (`--report md|html`), сгруппированные по хосту, сервису и выведенному типу актива, из тех же структурированных записей, что и вывод CLI.

## Область

- Строить отчёт из тех же `ScanRecord`, что рендерит CLI — единый источник истины, отдельный слой представления в `src/output/`.
- Группировки: по хосту (порты и сервисы под каждым IP), по сервису (какие хосты открывают данный сервис), по выведенному типу актива (из задачи 11, если обогащение включено).
- Метаданные скана обязательны в шапке: область целей, метка времени, версия инструмента, режим скана.
- Опциональная совместимость импорта/экспорта с распространёнными форматами данных сканеров (например, nmap XML), где практично — для интеграции с существующими пайплайнами.
- Не раскрывать секреты и сырые баннеры без необходимости: баннеры санитизируются (как в `src/scanner/service.rs`) и по умолчанию усечены; полный баннер — по явному флагу.

## Критерии приёмки

- [x] `--report md` и `--report html` генерируют отчёт из тех же `ScanRecord`, что и машинный вывод/CLI.
- [x] Метаданные содержат targets, timestamp (Unix), version и scan mode.
- [x] Группировки по хосту, сервису и device_type; неизвестные помечены `(unknown)`/`(unclassified)`, тип актива — только при `--classify`.
- [x] Баннеры очищены от control-символов и усечены до 80 символов; `--full-banners` включает полный санитизированный текст; HTML экранируется.
- [x] Тесты покрывают metadata/группировки, HTML-экранирование, усечение/полный баннер и CLI `--report`/`--report-file`.

## Вне области

- Интерактивные дашборды.
- Risk-scoring и вывод об уязвимостях (не задача Asphyxia — см. роадмап «Вне области»).


## Реализация

- `src/report.rs` — `ReportFormat` (`md`/`html`), `ReportMeta`, группировки `by_host`/`by_service`/`by_device`, санитизация и усечение баннеров, Markdown/HTML-рендер; в host-секции показываются MAC/PTR/ASN, если обогащение включено.
- `src/cli/mod.rs` / `src/main.rs` — `--report`, `--report-file`, `--full-banners` на `ps` и `as`; отчёт строится из тех же записей, что машинный вывод, и заменяет обычный вывод (в режиме `--watch` report-флаги отбрасываются).
- `src/output/mod.rs` — `ScanRecord` теперь `Clone`, чтобы один список отдавать и в emit, и в отчёт.
- README/`--help` обновлены.
