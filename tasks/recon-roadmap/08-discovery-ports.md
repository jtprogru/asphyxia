# Настраиваемые TCP-порты обнаружения

Фаза: 2 — Улучшение обнаружения хостов
Статус: Выполнено (выпущено в 0.11.0, 2026-11-08)
Зависит от: —
Роадмап: docs/recon-roadmap.md (Фаза 2)

## Цель

Сделать набор TCP-портов обнаружения настраиваемым (`--discovery-ports 80,443,22,3389,445,...`) вместо жёстко зашитого списка в `src/scanner/address.rs`.

## Область

- Вынести жёстко зашитые порты 80/443/22/3389 из `probe_address` (`src/scanner/address.rs:116`, константа `PROBE_PORTS` в `address.rs:28`) в именованный набор с CLI-переопределением.
- Принимать списки через запятую и именованные наборы (переиспользовать машинерию наборов портов из `src/scanner/well_known.rs`, где практично).
- Разумные дефолты сохранены; документировать, что более широкие наборы линейно увеличивают время обнаружения.
- Применяется и к `as` (address scan), и к любому raw-режиму обнаружения, добавленному позже.

## Критерии приёмки

- [x] `asphyxia as --discovery-ports 445,3389` пробирует для обнаружения ровно эти порты (через `scan_address_with_ports`/`scan_hosts_with_ports`).
- [x] При отсутствии флага поведение не меняется: используется `PROBE_PORTS` (80,443,22,3389).
- [x] Некорректные спецификации портов падают с ясной ошибкой валидации; порт 0 отвергается.
- [x] Структурированный вывод записывает пробу, подтвердившую хост (`discovery: "tcp"`); для ARP/ICMP — `arp`/`icmp`.
- [x] Тесты покрывают дефолтный набор (существующие), кастомный набор и разбор/валидацию спецификации.

## Вне области

- Комбинированный multi-probe отчёт (отдельная задача 09).


## Реализация

- `src/scanner/address.rs` — `scan_address_with_ports`, `scan_hosts_with_ports`, `scan_subnet_with_ports`, `scan_ip_range_with_ports`; старые функции остаются обёртками над `PROBE_PORTS`.
- `src/cli/mod.rs` / `src/main.rs` — `--discovery-ports <PORTS>` для `as`, разбор через `parse_ports`, запрет пустого набора и порта 0, предупреждение для `arp`/`icmp` о том, что набор влияет на TCP-откат.
- `src/main.rs` — набор прокинут через `scan_filtered` и TCP-откат ARP/ICMP.
- README и `--help` обновлены; кастомный набор покрыт юнит- и CLI-тестами.
